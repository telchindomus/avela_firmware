# Avela user guide

Avela plays internet radio over Wi-Fi. Use the knob and Back button to choose a station, control playback and open
the radio's screens. A local page on your phone or computer lets you edit stations and settings.

This guide covers an assembled Avela Piccolo with firmware installed. Its screen is not touch-sensitive. Piccolo and
Silk Taupe use the same controls; their colours and layout differ. Weather is available when included in the
installed firmware.

Start with [First start](FIRST_START.md). For a board that has no Avela firmware, use
[Install or recover the firmware](INSTALLATION.md).

## How to read the instructions

Radio, Stations, Info and Weather name screens on the device. Player, Wi-Fi, Access, Stations, Weather, Clock and
Board name tabs on the setup page. A press means a short press and release of the knob; a double press means two
quick presses. Hold means keep the knob pressed until its action occurs, then release it.

The instructions describe the radio's controls and settings. Enclosure details such as the location of a power
socket or a recessed button depend on the assembled device. Use the labels and instructions supplied with your
hardware.
