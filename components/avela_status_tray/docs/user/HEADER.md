# Status bar

The band above each screen shows the clock, Wi-Fi, volume and playback indication. It remains visible while you use
the screen menu or another page. The description below follows the official Piccolo and Silk Taupe skins; another
skin can draw the same information differently.

## Clock and Wi-Fi

Before the clock has synchronized, it shows `--:--` with no date. Use the
[Clock guide](../../../avela_clock/docs/user/CLOCK.md) to set a time zone or check synchronization.

Wi-Fi arcs indicate the connection and animate while joining. Signal bars describe the connected network; they do
not show whether a particular station or weather service is reachable.
[Info](../../../avela_system_info/docs/user/INFO.md) gives the connection details.

## Volume and LIVE

The volume bars show the requested volume. They are separate from the spectrum on Radio, which follows the audio
content.

The LIVE indicator distinguishes a request to play from actual playback. It shows an antenna while playback is
requested, outgoing waves while audio is playing, and an empty frame when stopped. An indication that playback is
requested does not guarantee that a stream has connected or that volume is above zero.

For a listening problem, check the message on the
[Radio screen](../../../avela_radio/docs/user/RADIO.md#read-the-player) as well as the status bar.
