# Avela firmware

> **Created by humans, extendable by AI.**

Avela is internet radio firmware for ESP32 devices. It combines MP3 playback, station management, Wi-Fi setup, an
optional weather screen, and firmware updates over the network. The firmware uses ESP-IDF and C++20.

To use an installed radio, start with the [user guide](docs/user/README.md). For all documentation, use the
[documentation index](docs/README.md). For development, read the
[architecture](docs/developer/ARCHITECTURE.md) and [coding standard](docs/developer/CODING_STANDARD.md), then the
reference for the component you are changing. [Build and flash](docs/developer/BUILD.md) explains the build
environment, USB installation, network updates, and checks.

Each component carries its own documentation. The index links to the component entry points and the shared guides
for writing skins.
